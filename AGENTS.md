# Agent Guide

This repository is **Public Transport Spy**: ESP32 OLED departure boards, a NestJS API (`api/`) and a Next.js dashboard (`frontend/`), plus PlatformIO firmware (`on-chip-software/`).

Everything an assistant needs is in [`CLAUDE.md`](CLAUDE.md): commands, architecture, and the rules and invariants (security, persistence, BFF, firmware). Deeper reference is in [`docs/`](docs/README.md). The files in [`agents/`](agents/README.md) only point to the right section.
